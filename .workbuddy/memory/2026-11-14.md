- `components/workspace/image-upload.tsx`：`serverUrl` 原本對影片副檔名一律回 null（重掛載後預覽消失）；改為 `acceptVideo` 時允許影片檔名走 ComfyUI view URL，並依副檔名渲染 `<video>` 預覽。
- 影片放大（SeedVR2 / vid_upscale）的來源參數是 `params.imageName`（沿用圖片參數），上傳走 `comfyuiClient.uploadVideo`（ComfyUI 無 /upload/video，複用 upload/image）。
- 驗證：`npm run typecheck && npm run lint` 通過。

### 追加：上傳後按 X 變成破圖
- 根因：`image-upload.tsx` 的 X 按鈕只做了 `setPreviewKind(null)`，沒清 `preview`；`url = preview || serverUrl` 仍取到已 revoke 的 blob URL → `<img>` 載入失敗顯示 alt 文字（截圖中的破圖）。
- 修法：X 內補 `setPreview(null)`、`setError(null)`、清 input value；「更換」與 file input 的 onChange 也清 value，讓重選同一檔案能再次觸發。
- 亦讓畫廊拖入的影片（多為 output 檔）經 `ensureInputRef` 搬進 ComfyUI input，避免 SeedVR2 找不到檔案。

### 追加：畫廊拖入影片仍顯示破圖
- 根因：`isVideo` 判斷用 `VIDEO_EXT.test(url)`，而 ComfyUI view URL 恆以 `&__host=...` 查詢參數結尾，`$/i` 錨點永不匹配 → 影片被當 `<img>` 渲染成破圖。改為用 `value`（純檔名）判斷。
- 畫廊拖放路徑補 `setUploading` 載入指示（await onGalleryDrop），大檔傳輸時不再無反應。
