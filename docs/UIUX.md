# Super Studio — 使用者介面與體驗設計 (UI/UX Design)

> 本文描述 Super Studio 的介面佈局、視覺風格與互動體驗設計。技術實作邏輯請參考 `spec.md`，需求與驗收標準請參考 `requirements.md`。

---

## 1. 設計原則

1. **一頁式工作台**：主要操作集中在單一頁面，減少跳轉。
2. **即時反饋**：每個操作都有明確的狀態回應（載入、成功、失敗、進度）。
3. **低學習成本**：預設參數即開即用，進階選項收斂在可展開區。
4. **可恢復**：任何參數組合都可保存、重載、分享。
5. **專業克制**：以內容為重，介面讓位於作品本身，不做過度裝飾。

視覺風格定位：**功能性工具**而非展示型產品。優先可讀性與操作效率，避免誇飾的漸層、陰影或動效。

## 2. 整體佈局

### 2.1 三欄式工作台（桌面）

```
┌──────────────────────────────────────────────────────────────┐
│  Header：Logo | 模式導航 | ComfyUI 狀態 | 主題 | 設定 | 歷史   │
├──────────────┬──────────────────────┬────────────────────────┤
│              │                      │                        │
│  左欄         │   中央 畫廊/結果      │   右欄 參數/設定       │
│  模式選單     │                      │   (依模式動態變化)      │
│  · 文生圖    │   ┌────┐ ┌────┐      │                        │
│  · 圖生圖    │   │IMG │ │VID │      │  [提示詞輸入]           │
│  · 文生影片  │   └────┘ └────┘      │  [模型選擇]             │
│  · 圖生影片  │   ┌────┐ ┌────┐      │  [參數控制]             │
│  · 圖片放大  │   │IMG │ │IMG │      │  [生成/中斷按鈕]        │
│  · 影片放大  │   └────┘ └────┘      │  [進度條 + 預覽]        │
│  · 自定義    │                      │                        │
│              │  生成中卡片(置頂)     │                        │
│  [生成佇列]   │                      │                        │
│              │                      │                        │
├──────────────┴──────────────────────┴────────────────────────┤
│  Footer：版本資訊、快捷操作                                  │
└──────────────────────────────────────────────────────────────┘
```

- **桌面（寬 ≥ 1024px）**：三欄並排。
- **平板（768–1024px）**：右欄縮為可拖出抽屜（Drawer）。
- **手機（< 768px）**：單欄；模式選單與參數面板改為底部 Sheet；結果在上方。

### 2.2 左欄 — 模式導航

- 垂直列表，每項含圖示 + 標籤。
- 當前模式高亮（accent 底色）。
- 底部顯示「生成佇列數」（來自 WebSocket status）。
- 每種模式說明文字（hover tooltip）。

### 2.3 中央 — 結果畫廊

- **網格視圖**：卡片式排列，自適應列數。
- **最新結果置頂**：新產生的媒體自動插入最前方並捲動顯示。
- **空狀態**：顯示引導插圖 + 提示「輸入提示詞開始創作」。
- **連線狀態敏感**：未連線時顯示「請先連接 ComfyUI」引導卡。

### 2.4 右欄 — 參數/設定（依模式動態）

右欄內容隨左欄選的模式切換，提供對應控制項（詳見 §5）。

## 3. 顏色與主題

### 3.1 色彩基調

整體採**中性、低飽和**的藍灰調，避免鮮豔主色，營造專業、冷靜的創作工具氛圍。參考 Figma、Linear 等工具的克制配色。

- **不採用任何紫色系**。
- 主色使用**沉穩的藍灰（slate）**，強調色（用於主按鈕）使用**深藍（slate-800 / blue-700）**。
- 背景與邊框以低對比灰階構成，讓內容（圖片/影片）成為視覺主角。
- 飽和色僅保留給**狀態語意**（成功/警告/錯誤），不作為裝飾。

### 3.2 色板（shadcn/ui 語意色）

| 角色 | 亮色 | 暗色 | 用途 |
|------|------|------|------|
| `background` | 灰白 (#f8fafc) | 深灰藍 (#0f172a) | 頁面底 |
| `foreground` | 深灰 (#1e293b) | 淺 (#f1f5f9) | 主要文字 |
| `primary` | 深藍 (#1e40af) | 淡藍 (#3b82f6) | 主按鈕/強調 |
| `secondary` | 淺灰 | 深灰 | 次要元素 |
| `muted` | 更淺灰 | 更深灰 | 弱化文字/輸入底 |
| `accent` | 淺藍灰 | 深藍灰 | 懸停/選中 |
| `success` | 綠 | 綠 | 連線成功/完成 |
| `destructive` | 紅 | 紅 | 錯誤/刪除 |

### 3.3 色調原則

- 介面 90% 為灰階；僅 10% 用於功能語意色。
- 按鈕、連結、啟用態使用同一藍色，不另立多種強調色。
- 卡片與背景的對比保持溫和，避免刺眼。

### 3.2 主題切換

- 亮/暗/系統 三選一，位於 Header。
- 切換即時生效，偏好持久化。

### 3.3 連線狀態指示色

| 狀態 | 顏色 | 圖示 |
|------|------|------|
| 已連接 | 綠 | 實心圓點 |
| 連線中 | 黃 | 脈動圓點 |
| 未連接 | 紅 | 空心圓點 |

## 4. 字體與排版

- 主字體：Inter（或系統無襯線 stack）。
- 等寬字體：僅用於數值輸入與工作流 JSON 檢視。
- 標題：Semibold；內文：Regular。
- 行高：1.5；基準字級 14–16px。

## 6. 生成進度與狀態回饋

### 6.1 生成中卡片（中央置頂）

```
┌─────────────────────────────┐
│ 生成中...  ██████░░░░  60%    │
│ 目前節點: KSampler            │
│ 取樣 12/20 步                 │
│  ┌─────────────────────┐    │
│  │   即時預覽            │    │
│  └─────────────────────┘    │
│  [中斷生成]  │ 剩餘佇列: 1   │
└─────────────────────────────┘
```

### 6.2 進度呈現規則

| 事件 | 顯示 |
|------|------|
| 提交成功 | Skeleton 卡片出現，顯示「佇列中」 |
| `executing` | 顯示「目前節點」名稱 |
| `progress` | 進度條 + 「x/y 步」 |
| 預覽訊息 | 即時縮圖顯示在進度卡 |
| 完成 | 卡片轉為結果卡，進度條滿格變綠 |
| 失敗 | 卡片變紅 + 錯誤訊息 toast |

### 6.3 中斷操作

- 可從進度卡或右欄「中斷」按鈕觸發。
- 點擊後按鈕變為「正在中斷...」並禁用，直到收到中斷確認。
- 中斷後保留部分節點輸出（若有）。

## 7. 畫廊互動細節

### 7.1 媒體卡片

```
┌──────────────┐
│              │
│   [縮圖/預覽]  │   ← hover 出現操作列
│              │
│  ┌──────────┐│
│  │ 下載 放大 ││   ← 下載、放大、詳情
│  └──────────┘│
│  提示詞摘要    │
│  時間戳        │
└──────────────┘
```

- hover 上浮 + 陰影 + 操作列淡入。
- 影片卡片中央顯示播放按鈕。

### 7.2 圖片燈箱

- 點擊圖片 → 全螢幕燈箱。
- 支援：放大/縮小、拖曳瀏覽、左右切換、Esc 關閉。
- 顯示 meta：解析度、檔案大小、提示詞、時間。

### 7.3 影片播放

- 內嵌 `<video controls>`。
- 點擊卡片 → 開啟專用檢視，可全螢幕。
- 顯示 meta：時長、解析度、檔案大小。

### 7.4 放大操作入口

- 卡片操作列「放大」→ 自動切換到對應放大模式，並預先帶入該媒體為來源。
- 放大完成後新增卡片，並彈出「前後對比」浮層（左右滑動比較）。

### 連接測試流程

1. 點「測試連接」→ 按鈕轉為載入動畫。
2. 成功：綠勾 + 顯示系統資訊卡。
3. 失敗：紅叉 + 錯誤訊息（「無法連線，請確認 ComfyUI 已啟動」）。
4. 地址改變 → 顯示「未保存」提示，需點「保存」。

## 10. 狀態與給用戶的訊息

### 10.1 Toast 訊息

| 類型 | 樣式 | 範例 |
|------|------|------|
| 成功 | 綠邊框 | 「圖片已生成」 |
| 錯誤 | 紅邊框 | 「工作流驗證失敗：節點 3」 |
| 資訊 | 灰/藍 | 「正在上傳參考圖...」 |
| 警告 | 黃邊框 | 「未連接 ComfyUI」 |

- 自動消失（成功 3s、其他 5s）。
- 可用於長流程的中斷提醒。

### 10.2 空狀態與引導

每個無內容區域都有引導性空狀態，附簡短說明與下一步動作按鈕。

## 11. 鍵盤與無障礙

- **快捷鍵**：`Ctrl/Cmd+Enter` 生成、`Esc` 關閉燈箱/彈窗。
- **無障礙**：
  - 所有控制項有 `aria-label`。
  - 顏色不作為唯一資訊傳遞（輔以圖示/文字）。
  - 支援鍵盤 Tab 導覽。
- **載入**：非同步操作有 skeleton/spinner 而非空白。

## 13. 互動動效（克制）

動效僅用於強化狀態認知，不為裝飾。

- 按鈕 hover → 背景微變（120ms）；active → 按下回饋。
- 模式切換 → 右欄內容淡入（150ms）。
- 新卡片出現 → 淡入（150ms）。
- 進度條更新 → 平滑過渡（width transition 300ms）。
- 連線狀態 → 靜態色點，不建議脈動動畫（減少干擾）。

原則：動效單次 150–300ms，避免重複、無限或彈跳效果。

## 14. 使用情境流程示例

### 情境 A：從文生圖到放大

```
1. 用戶輸入提示詞 → 點「生成圖片」
2. 見進度卡 → 60% → 完成 → 新卡片置頂
3. hover 卡片 → 點「放大」→ 自動切到「圖片放大」模式
4. 來源圖片已帶入 → 選 4x → 點「放大圖片」
5. 完成 → 對比浮層（前後 1024×1024 vs 4096×4096）
6. 用戶點「下載」保存最終檔
```

### 情境 B：圖生視頻

```
1. 左欄點「圖生視頻」
2. 上傳首幀（可選尾幀）
3. 輸入動作描述 → 設時長 5s → 開 Turbo
4. 點「生成影片」
5. 見進度 + 無即時預覽（影片較慢）→ 完成出卡
6. 點卡片播放影片 → 下載
```
